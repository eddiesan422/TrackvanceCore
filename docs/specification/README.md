# Contratos generados del producto 0.8.0

Los contratos de modelos y permisos de esta carpeta se exportan desde el runtime
mediante `python scripts/export_contracts.py`; CI verifica estos archivos como
parte del producto y no requiere acceso al repositorio documental privado.

La fuente y el PDF v1.1 oficiales viven en
[TrackvanceCore-docs](https://github.com/eddiesan422/TrackvanceCore-docs/tree/main/docs/specification).
El generador se conserva en `scripts/docs/build_specification.py` y recibe
`--docs-root RUTA_DOCUMENTACION/docs`. La versión documental v1.1 es independiente
de la versión de producto 0.8.0.
