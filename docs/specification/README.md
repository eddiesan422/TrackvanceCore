# Especificación técnica

Esta carpeta conserva la copia versionada de la **Especificación Técnica v1.1**
correspondiente a la entrega de implementación `0.3.0` del 16 de septiembre de
2026.

- `Trackvance_Core_Especificacion_Tecnica_v1.1.md`: fuente editable.
- `Trackvance_Core_Especificacion_Tecnica_v1.1.pdf`: documento publicado y
  validado visualmente, con 26 páginas y 23 marcadores.
- `validation_results_0.3.0.json`: resultados certificados usados al generar
  la sección de aceptación.

El nombre v1.1 identifica la revisión contractual de la especificación; `0.3.0`
identifica la versión del software descrita por esta copia.
